## ⚡ Running Locally

You can preview the portfolio immediately on your computer:

### Option 1: Open Directly
Double-click [`index.html`](./index.html) in your file explorer.

### Option 2: Run a local static server
```bash
# Using Python
python -m http.server 3000

# Or using npx
npx serve .
```
Then open `http://localhost:3000` in your browser.

## 🌐 Deploying to Vercel (1-Click)

1. Create a repository on GitHub (e.g. `portfolio-website`).
2. Push your code to GitHub.
3. Log in to [Vercel](https://vercel.com/) with GitHub.
4. Click **Add New** &rarr; **Project** &rarr; **Import** your `portfolio-website` repository.
5. Click **Deploy** &rarr; Your public `https://your-name.vercel.app` link will be live in 20 seconds!
